# Tipos de página

Ofereça ao cliente a primeira coluna. `post` e `redirect` existem na LeadLovers, mas não são oferecidos por esta skill.

| Para o cliente | Para que serve | `type` | Formulário de captura |
| --- | --- | --- | --- |
| Captura | Juntar contatos em troca de algo (e-book, aula, cupom). Recomendada para começar um funil | `capture` | Sim |
| Obrigado ou próximos passos | Aparece depois do cadastro: agradece e diz o que vem a seguir | `next-steps` | Não |
| Recompensa | Entrega o que foi prometido na captura | `reward` | Não |
| Vendas | Apresenta e vende um produto, com o botão de compra | `sale` | Não |
| Download | Página para baixar um material | `download` | Não |
| Lançamento | Página de um lançamento, que também capta interessados | `launch` | Sim |
| Complementar | Página de apoio, sem um papel específico no funil | `complementary` | Só se pedido |
| Blog | Artigo ou conteúdo | `blog` | Só se pedido |

O botão de compra de uma página de vendas leva ao link de pagamento que o cliente informar; a skill não cria checkout.
